## Preparazione Python Coding Interview

Da studiare prima del colloquio:
- Strutture dati Python: list comprehensions, dict, set, defaultdict, Counter
- Pattern agentic: come strutturare tool use, function calling, orchestrazione con Python
- Librerie: familiarità con LangChain/LangGraph o Pydantic AI (probabilmente usate da Doctolib)
- Testing Python: pytest, mock, fixtures
- Typing: type hints, dataclasses, Pydantic models
- Algoritmi base: non è un FAANG coding interview, ma la fluidità in Python conta
