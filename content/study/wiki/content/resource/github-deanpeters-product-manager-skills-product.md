# GitHub - deanpeters/Product-Manager-Skills

**Repository open source · Product Management skills framework per agenti AI**

Repository open source creato da [[../person/dean-peters|Dean Peters]] (Productside) contenente 42 "skill" — framework, template e flussi conversazionali riutilizzabili — pensate per insegnare ad agenti AI (Claude Code, Cowork, OpenAI Codex, ChatGPT) a svolgere lavoro di product management in modo professionale: dalla stesura di PRD alla conduzione di interviste di discovery, dalla scelta del framework di prioritizzazione alla scomposizione di epic. Le skill sono organizzate in tre livelli — Workflow Skills (processi end-to-end su settimane), Interactive Skills (flussi conversazionali guidati) e Component Skills (template puntuali) — e si basano su metodi di autori affermati come Geoffrey Moore, Teresa Torres e sull'approccio "Working Backwards" di Amazon.
