# .NET

**Piattaforma software open source e cross-platform** · Microsoft

.NET è la piattaforma di sviluppo open source e multipiattaforma di Microsoft, che supporta linguaggi come C#, F# e Visual Basic, usata per costruire applicazioni web, desktop, mobile e cloud.
