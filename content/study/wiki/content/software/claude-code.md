# Claude Code

**Agente di coding AI a riga di comando** · Anthropic

Claude Code è lo strumento agentico di Anthropic per la scrittura di codice: un agente che vive nel terminale (o integrato in un IDE), legge e comprende una codebase, ed esegue compiti — modificare file, eseguire comandi, gestire workflow git — tramite istruzioni in linguaggio naturale. Il suo funzionamento si basa su un ciclo (il "**loop**") in cui il modello chiama strumenti (tool) per agire sul sistema, ricevendone i risultati come nuovo contesto, fino a produrre una risposta diretta — l'insieme di questo ciclo più il sistema che costruisce contesto, espone strumenti e gestisce i permessi è definito, nell'archivio, l'**harness** dell'agente.
