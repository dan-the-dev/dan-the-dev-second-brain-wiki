# OpenAI Codex

**Modello AI orientato alla programmazione** · OpenAI

Codex è il modello di OpenAI specializzato nella generazione e comprensione di codice, alla base di diversi strumenti di coding assistito da AI.

Un'analisi tecnica dell'architettura di [[claude-code|Claude Code]] lo cita come il termine di paragone più diretto fra i coding agent concorrenti: Codex è scritto in Rust (a differenza del TypeScript di Claude Code) e condivide meccanismi simili — ciclo di chiamata al modello, uso di strumenti — pur con un flusso diverso; la fonte segnala anche una voce di corridoio (non confermata, raccolta da Reddit) secondo cui Claude Code starebbe venendo riscritto in Rust proprio per avvicinarsi a Codex (vedi [[../video/come-funziona-claude-code-spiegato-da-un-dev|Come funziona CLAUDE CODE spiegato da un Developer]]).
