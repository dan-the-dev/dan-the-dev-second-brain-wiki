# Redis

**Database chiave-valore in-memory** · creato da [[../person/salvatore-sanfilippo|Salvatore Sanfilippo]]

Redis è un database in-memory chiave-valore, usato principalmente come cache, message broker e store per dati ad accesso rapido. È stato creato dal programmatore italiano Salvatore Sanfilippo.
