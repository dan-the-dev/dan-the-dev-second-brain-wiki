# Cloud Code

**Plugin IDE cloud** · Google

Cloud Code è una raccolta di plugin IDE (VS Code, JetBrains, Cloud Shell Editor) assistiti da AI per semplificare build, deploy e debug di applicazioni su Google Cloud, con supporto integrato per Kubernetes, Cloud Run, Skaffold e Gemini Code Assist.
