# Test-driven development

**Metodo di scrittura del codice**

Il test-driven development (TDD) è una pratica di sviluppo software in cui il test automatico viene scritto prima del codice di produzione, seguendo un ciclo breve e ripetuto: si scrive un test che fallisce (rosso), si scrive il minimo codice necessario per farlo passare (verde), si migliora la struttura del codice mantenendo i test verdi (refactor).
