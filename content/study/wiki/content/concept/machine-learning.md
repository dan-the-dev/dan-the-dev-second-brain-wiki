# Machine learning

**Studio di algoritmi che migliorano tramite l'esperienza**

Il machine learning è il ramo dell'intelligenza artificiale che studia algoritmi capaci di migliorare automaticamente le proprie prestazioni su un compito attraverso l'esposizione a dati, senza essere esplicitamente programmati passo per passo per quel compito. Comprende famiglie di approcci molto diverse (apprendimento supervisionato, non supervisionato, per rinforzo) ed è il fondamento tecnico su cui si basano i moderni large language model.
