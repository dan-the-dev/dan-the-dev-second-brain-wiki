# Extreme programming

**Metodologia di sviluppo software agile**

L'Extreme Programming (XP), creato da Kent Beck alla fine degli anni '90, è una delle metodologie fondanti del movimento agile. Porta all'estremo pratiche di ingegneria del software ritenute efficaci — test-driven development, pair programming, integrazione continua, refactoring costante, rilasci frequenti — partendo dal presupposto che se una pratica funziona bene con moderazione, applicarla con intensità porti a risultati ancora migliori. XP è il contesto storico e concettuale in cui è nato il TDD stesso, ed è alla base di gran parte del pensiero su pratiche tecniche agili presente in questo archivio.
