# Extreme Programming (XP)

Il testo fondativo di Kent Beck, [[../content/book/extreme-programming-explained|Extreme Programming: Explained]] (i cinque valori, i principi ponte, le pratiche primarie come pair programming e ten-minute build), è affiancato da due contenuti più pratici e situati: il video [[../content/video/async-code-reviews-are-choking-your-companys|Async Code Reviews Are Choking Your Company's Throughput]], che critica un pattern (le code review asincrone) che l'XP originario avrebbe risolto con il pair programming, e [[../content/video/l-effetto-sistemico-di-extreme-programming-con|L'effetto sistemico di eXtreme Programming con Nicola Moretto]], una testimonianza diretta sull'impatto organizzativo dell'adozione di XP.
